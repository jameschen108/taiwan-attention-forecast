## 1. 目標與核心決策

本次改造的目標，是讓專案從歷史關聯研究，延伸成能在固定時間產出未來預測、保存預測紀錄，並持續檢驗預測價值的系統。

第一版採以下明確範圍。本文所有新門檻均為建議預設值，不是已驗證的最佳參數；開始正式評估前，應將它們固定在設定檔與實驗登記表中。

| 項目 | 第一版決策 |
|---|---|
| 主要用途 | 提供個股未來相對強弱排名與觀察名單 |
| 預測頻率 | 每週一次，交易週開始前完成 |
| 資料截止 | Asia/Taipei 時區，每週一 00:00；只使用此時間之前已取得的資料 |
| 主要期間 | 下一個日曆週的交易期間，簡稱 1 週 |
| 次要期間 | 接下來 4 個日曆週的連續持有期間，簡稱 4 週 |
| 主要標籤 | 個股期間總報酬減去同期間指定基準總報酬 |
| 基準 | 建議使用 0050 作為可觀察的比較標的；須新增並驗證其價格與公司行動資料 |
| 主要模型輸出 | 預測超額報酬與個股排名 |
| 次要模型輸出 | 跑贏基準的機率；不等同股價上漲機率 |
| 第一版模型 | Ridge、邏輯斯迴歸；再比較一組受限的梯度提升樹 |
| 第一版交易驗證 | 只做 1 週、無槓桿、只做多的模擬，與同規則基準策略比較 |
| 成功標準 | PTT 在時間外推評估中，對價格基準提供穩定增益 |

0050 是大型股 ETF 比較標的，不代表完整市場，也不代表本研究樣本。若要改用加權指數、報酬指數或產業基準，須建立另一個具明確價格／總報酬定義的實驗版本，不可在看到結果後替換基準並沿用原結論。

保留現有論文研究管線與 diagnostic 標記，另外建立預測管線。原文件中的研究規範是理解現況的材料，並非本次要求執行的指令。本文不要求先補齊所有論文控制變數才開始預測實驗。

## 2. 現況判讀與改造理由

檢視主要程式、文件及現有稽核輸出後，可確認：

- 面板有 123,828 列、260 檔有效個股、506 個週標籤。
- 設定的主樣本期間為 2015-05-01 至 2024-12-31；W-SUN 對齊後，面板末端週標籤為 2025-01-05。
- PTT 封存截止於 2025-01-24，尚不足以產生目前時點的新預測。
- 現有分析以固定效果迴歸、機制分析、事件研究與訊號排序為主，尚未有獨立的預測訓練、時間切分、模型保存與線上推論流程。
- 現有結果皆為 diagnostic。歷史報酬關聯與成本後投組結果，尚不足以證明可實作的預測價值。
- 名單由較晚時點選出，存在事後選樣限制，不能當成歷史投資人當時可知的完整投資宇宙。

這些判讀以目前程式與現有輸出為依據，本次未重跑分析。專案各摘要可能存在版本差異，實作時應將結果表、程式版本與資料指紋一起保存，避免混用不同批次數值。

| 既有資產 | 沿用方式 |
|---|---|
| 股票代號、簡稱與碰撞消解 | 延續使用，保存規則版本與有效期間 |

### 2.2 預測管線新增的六個能力

1. 依「當時可用時間」重建資料。
2. 將特徵、未來標籤與即時預測名單分離。
3. 按時間訓練與驗證，禁止用未來資料選模型。
4. 比較相同樣本上的價格模型與價格加 PTT 模型。
5. 使用一致的持有期間、成交規則與交易成本回測。
6. 保存每次預測，等答案實現後再評分。

## 3. 預測問題、研究假說與範圍

### 3.1 主要問題

在已知價格、成交量、流動性與個股基本結構後，PTT 關注度是否能改善未來 1 週相對報酬的預測？

定義兩個主要比較：

- **模型 A：價格基準。** 僅使用當時可用的價格、成交、規模及市場資訊。
- **模型 B：價格＋PTT。** 使用 A 的全部特徵，再加入關注度特徵。

以同一週、同一股票、同一標籤、同一時間切分的預測作成對比較。模型 B 是否優於 A，才是 PTT 的增量預測價值；B 是否優於隨機猜測不足以回答此問題。

### 3.2 次要問題

| 任務 | 定義 | 優先度 |
|---|---|---|
| 4 週相對強弱 | 連續持有 4 個日曆週的超額報酬 | 第二階段 |
| 跑贏基準機率 | 期間超額報酬大於 0 的機率 | 第一階段的次要輸出 |
| 交易活躍度 | 未來一週相對歷史基準的日均周轉率變化 | 第二階段 |
| 討論熱度 | 未來一週文章數與是否出現討論 | 第二階段 |
| 新聞增量 | B 加入有可靠時間戳的新聞後是否改善 | 第三階段 |

現有研究顯示周轉率值得進一步測試，但不能把歷史顯著關聯直接當成樣本外預測成功。不得因報酬任務失敗，就把另一個任務成功寫成原任務成功。

第一版不涵蓋大盤方向、精確目標價、長期產業成長、盤中交易、自動實盤下單或因果推論。

## 4. 時間契約：什麼資料可以在什麼時候使用

### 4.1 必要時間欄位

| 欄位 | 定義 |
|---|---|
| `event_at` | 事件發生時間，例如貼文發表、交易發生 |
| `published_at` | 來源正式公開此筆資料的時間；若無可靠紀錄須標示未知 |
| `ingested_at` | 系統首次取得該資料版本的時間 |
| `available_at` | 此版本可供模型使用的最早時間 |
| `as_of` | 本次資訊截止時間 |
| `generated_at` | 本次預測完成時間 |
| `entry_at` | 標籤假設的進場時間，或回測實際模擬成交時間 |
| `label_end_at` | 標籤對應的期間結束時間 |
| `label_available_at` | 系統已取得足夠資料、可以計算此標籤的時間 |

正式前瞻模式下，`available_at` 至少不能早於實際取得時間與公開時間。若資料在發布後修訂，每個修訂版本有自己的 `available_at`，不得覆蓋舊版本。

```text
已發生觀測的必要條件：event_at < as_of 且 available_at < as_of
可用訓練標籤的必要條件：label_end_at < fit_cutoff 且 label_available_at < fit_cutoff
```

已公告但尚未生效的休市日曆、除權息行程等，依公告／取得時間判斷是否可知；其未來生效日可作已知行程，但不得混入尚未發生的實際成交或給付結果。第一版不額外使用公告事件預測特徵。

第一版 `fit_cutoff = as_of`。交易期開始前若模型尚未產出，本次預測視為逾時，不能用後補結果假裝準時。

### 4.2 每週執行節奏

1. 持續抓取來源並保存新增或修訂資料。
2. 每週一 00:00 固定資訊快照，納入此前已取得的前週資料。
3. 00:00 之後執行品質檢查、建立特徵，並在排定重訓週更新模型。
4. 建議預測在週一 08:00 前完成；若週一休市，仍按原週期產出，交易延至該週首個開市日。
5. 若本週完全休市，記錄 `schedule_skip`，不假造本週報酬、不移用下下週作為一週標籤。
6. 下一期答案完整取得後，補寫標籤與評估紀錄，原預測不覆寫。

週一凌晨之後才抓到的週日文章不納入本次正式快照。若希望使用週一盤前資訊，另建盤前版本並重新定義截止時間、文章窗口與回測，避免與本規格混用。

### 4.3 歷史封存沒有取得時間怎麼辦

不能把今天補抓的歷史資料假稱為系統當年已取得。分成三種證據等級：

| 等級 | 定義 | 可支持的說法 |
|---|---|---|
| `retrospective_proxy` | 缺歷史版本或取得時間，只能依發布時間／延遲假設重建 | 歷史近似外推實驗 |
| `historical_pit` | 有可驗證的歷史發布版本、可用時間與當期宇宙 | 歷史時點可用資料回測 |
| `prospective` | 在真實時點保存資料與預測，再等待答案 | 前瞻預測紀錄 |

舊 PTT 文章可能在發表後編輯；沒有版本歷史時，正文不能自動視為發表當下的內容。此限制要進入資料清單與結果報告。歷史可用時間假設須逐來源設定與揭露。

## 5. 股票宇宙與資料更新

### 5.1 股票宇宙的三種用途

**既有固定名單：** 可先完成方法開發，但所有歷史結果標記 `ex_post_universe`。時間切分不會自動消除事後選樣偏誤。

**歷史時點宇宙：** 若要宣稱策略可於歷史實作，需依當時已上市、未下市、市場別、證券種類與已公開狀態建立名單，包含後來下市或不再活躍的股票。

**前瞻固定觀察名單：** 可以從規格凍結日起固定現有名單，保存後續上市、下市與停牌處理。這能檢驗此名單以後的預測，不能修復其較早年度的代表性。

上市日期過濾不足以修復生存者偏誤。產業、簡稱、股票代號、轉板紀錄與可交易狀態也需要有效期間，不得直接將最新分類套回全部歷史。

### 5.2 第一版必要資料

| 資料 | 最低內容 | 時間要求 |
|---|---|---|
| 個股日行情 | 開高低收、成交股數、成交金額 | 最近交易日完整且在截止前可用 |
| 基準日行情 | 0050 同期行情及公司行動 | 與個股標籤口徑一致 |
| 公司行動 | 除權息、拆併股、減資及現金給付 | 區分公告時間、生效日與支付日 |
| PTT | 文章 ID、發表時间、標題、正文、取得版本 | 有來源覆蓋與去重紀錄 |
| 股數、持股 | 發行股數、外資持股比例 | 只能向後對齊已公開資料 |
| 交易日曆 | 預定開市日與當時已公布的變更 | 即時使用公布日曆；事後保存實際日曆 |
| 股票基本資料 | 名稱、市場、上市／下市與狀態有效期間 | 支援宇宙快照 |

新聞、財報、月營收與分析師資訊屬後續增量資料。若新增月營收，要按公告時間使用，不能按營收所屬月份提早放入特徵。

### 5.3 抓取與品質規則

- 原始資料追加保存，以來源鍵、版本與內容指紋去重。
- 保存成功／失敗批次、預期區間、實際覆蓋區間、修訂與延遲。
- 區分「確定沒有文章」與「沒有完整抓到文章」。只有前者可以補零。
- 確認 PTT 整週完整後，才使用完整週的文章計數；不以部分計數冒充整週。
- 市場價格缺失不得補成零；股數為零、負數或單位不明時不得計算周轉率與市值。
- 若 PTT 來源不完整，B 模型本期不產生正式分數。可改用已驗證的 A 模型，但需標示實際模型與原因。
- 若價格或基準的核心資料不完整，受影響的預測／交易停止，留下明確狀態。

## 6. 標籤定義

### 6.1 期間與交易日

令 `w` 為資訊截止前、以星期日結束的特徵週。

- `entry_at`：下一個日曆週 `w+1` 的首個實際市場交易日開盤。
- `end_1w`：`w+1` 的最後一個實際市場交易日收盤。
- `end_4w`：從 `w+1` 到 `w+4` 期間最後一個實際市場交易日收盤。
- 1 週可只有 2、3 或 4 個交易日，不因假日而刪除；另外記錄期間交易日數。
- 4 週標籤是連續持有期間，包含跨週跳空。
- 若起始目標週完全休市，本期記為 `schedule_skip`，兩種期間均不開新部位。

停牌個股不能以該股較晚第一次成交偷偷改寫標籤起點。標籤價格不可取得時，記 `entry_unavailable`；即時預測名單仍保留，回測依未成交規則處理。

### 6.2 總報酬

主要標籤採不再投資現金股利的期間總報酬。以初始買入一股為例：

```text
R_i,h = (Q_end × P_end + cash_distributions + receivables_end) / P_entry − 1
```

其中 `Q_end` 反映期間拆併股、股票股利與減資後的持股數；現金給付包含期間取得權利的股利、減資退還等，已入帳現金與應收款不得重複計算。不主動追加資金參與認購，若遇需估值的配股權利等特殊事件，依事先固定規則處理；無法可靠估值時記錄未解決狀態。

還原價比率可以作為開發階段的近似標籤，但需標記 `adjusted_price_proxy`。必須通過與公司行動帳本的對照，才可稱為上述總報酬。不能一面用含股利還原價格，一面再加一次現金股利。

後向還原價格不必一律禁用：未來共同還原因子可能在歷史報酬比率中相消；但絕對還原價與不相消的特徵可能受未來事件影響。需逐欄驗證「加入未來事件，不應改變截止前特徵」，不能只靠欄名判定安全。

### 6.3 主要與次要標籤

```text
y_excess_1w = R_stock,1w − R_benchmark,1w
y_excess_4w = R_stock,4w − R_benchmark,4w
y_outperform_h = 1 if y_excess_h > 0 else 0
```

`R_benchmark,h` 必須使用與個股相同的市場起訖時間及總報酬口徑。第一版不將交易成本扣進主要預測標籤，成本交給交易模擬處理，避免個股標籤依部位大小而改變。

`p_outperform_1w = 0.60` 表示模型估計跑贏 0050 的機率為 60%，並非估計上漲 60%、報酬 60%，也不是保證準確率。

### 6.4 活躍度與熱度任務

活躍度採未來週日均周轉率相對過去八個完整週日均周轉率的對數變化：

```text
y_activity = log1p(mean_daily_turnover_next_week)
             − mean(log1p(mean_daily_turnover_past_8_weeks))
```

歷史八週截至特徵週 `w`，計算時全部已知；不含下一週。休市週不視為周轉率零，需按預定缺值規則處理。

熱度任務預測 `next_week_article_count` 與 `P(next_week_article_count > 0)`。計數與是否出現討論分開評估，避免大量零值讓永遠預測零看似表現很好。可從過去八週平均文章數、過去非零比例作為基準，再測試 Poisson 或兩階段模型。

### 6.5 標籤缺值與樣本選擇

- 預測名單與下單名單不得依未來標籤是否完整篩選。
- 訓練只使用已成熟且可靠的標籤，同時記錄因下市、停牌、資料缺失而不可學習的樣本比例。
- 評分時可在可評分的共同樣本比較 A/B，但必須另報全部預測的涵蓋率與缺失原因，並對非隨機缺失做敏感度分析。
- 無法成交者在策略帳本保留現金；已持有而無法賣出者仍是持倉，不能刪掉或直接當成零報酬。

## 7. 特徵設計

### 7.1 A：價格基準特徵

| 類型 | 第一版特徵 |
|---|---|
| 報酬與動能 | 剛結束一週報酬、過去 4／12／26 週連續期間報酬 |
| 波動 | 過去 20／60 交易日日報酬波動度 |
| 成交 | 過去 20 日日均成交金額、最近一週相對成交量 |
| 流動性 | 過去 20 日 Amihud、零成交日比例、日均周轉率 |
| 規模與結構 | 截止時可知市值的對數、上市年資、當期產業 |
| 持股 | 可用時的外資持股比例、最近已公開變動 |
| 市場狀態 | 基準近期報酬、20 日波動與過去回撤 |
| 品質 | 欄位缺失旗標、資料距截止日天數、有效觀測數 |

現有 `ret_lag1` 不包括剛結束這週的 `ret`。週末預測時 `ret` 已可知，應納入 A，避免把近期價格效應誤歸給關注度。

現有 `ret_lag4`／`ret_lag25` 是過去週報酬平均，不等於連續持有的累積動能。新特徵使用不同名稱與明確公式，避免同名換義。

### 7.2 B：增加 PTT 特徵

| 類型 | 第一版特徵 |
|---|---|
| 水準 | 整週、週間、週末文章數的 `log1p` |
| 異常程度 | 整週、週間、週末異常關注度 |
| 變化 | 本週與上週計數差、近 4 週計數趨勢 |
| 稀疏度 | 過去 52 週非零週數、平均文章數、歷史有效週數 |
| 起始事件 | 完整觀測下，連續 8 週零討論後首次出現討論 |
| 內容結構 | 原創標的文、心得／請益、新聞類文章數 |
| 討論時段 | 週末占比、非交易時段占比，分母為零另設旗標 |
| 辨識品質 | 僅代號辨識旗標、大量清單型貼文排除比例 |

異常關注度維持：

```text
AbnAtt_i,w = log1p(Att_i,w)
             − mean(log1p(Att_i,w−8), …, log1p(Att_i,w−1))
```

最近八週需完整，否則保持缺值。52 週稀疏度除了非零週數，還要保存 `history_weeks_available`；不足 52 週標記 `insufficient_history`，不可把新上市或資料不足誤判為長期沉默。

先裁掉上市前與資料未覆蓋的週，再計算滾動特徵。現有流程先建立完整格點、算完特徵才刪上市前列，可能讓上市前填零進入回顧窗；預測版本要修正順序。

第一版不使用缺時間戳的推文、不以文章發表時間替代推文時間。情緒模型與 LLM 文字特徵放到後續實驗，使用當時正文快照並驗證標註品質；現代模型可能知道歷史事件結果，必須另評估其回溯污染風險。

### 7.3 同週橫斷面特徵

在 `as_of` 已知的股票集合內，可以計算同週排名或產業平均；這本身不等於使用未來資訊。但名單、權重、產業分類與輸入資料都必須在當時已知，不可依下週報酬是否缺失決定計算成員。

### 7.4 缺值、標準化與白名單

- 原始表與標準化資料表保留真實缺值，不覆寫為填補值。
- 線性模型的前處理可使用訓練區間中位數＋缺失旗標；這是新的模型內處理規則，與原研究缺值政策分離。
- 訓練期全空的欄位明確移除並保存清單，不能從驗證期估計填補值。
- 數值標準化、裁切界線、編碼與任何特徵篩選，全部在每個訓練折內估計。
- 第一版線性模型採訓練集整體標準化，稀疏度另外編碼；不直接沿用整段樣本分層標準化。
- 樹模型可保留原生缺值，但品質旗標仍需保留；HistGradientBoosting 支援 NaN，實際套件版本需鎖定。[4]
- `X` 必須由版本化白名單產生，不能使用「所有數值欄位」。`ret_next`、`ret_fwd*`、`y_*`、未來市場資料與標籤狀態禁止入模。

前處理只從訓練資料學習、再套用到新資料，是避免資料洩漏的基本做法。[1]

## 8. 模型、比較矩陣與訓練規格

### 8.1 實驗矩陣

| 編號 | 模型 | 特徵 | 用途 |
|---|---|---|---|
| M0 | 常數預測 | 過去成熟標籤的平均／事件率 | 最低比較基準 |
| M1 | Ridge | A | 主要價格模型 |
| M2 | Ridge | A＋PTT | 與 M1 比較，隔離 PTT 增益 |
| M3 | 邏輯斯迴歸 | A | 跑贏基準機率 |
| M4 | 邏輯斯迴歸 | A＋PTT | 機率任務的 PTT 增益 |
| M5 | 梯度提升樹 | A | 非線性價格基準 |
| M6 | 梯度提升樹 | A＋PTT | 非線性增量比較 |

M1/M2 為主要比較，1 週為主要期間。M3/M4、M5/M6 與 4 週屬次要分析，不能任挑最佳結果作為主要結論。新聞實驗必須在有共同新聞覆蓋的期間重跑 A/B/C，不能把不同期間的指標直接相減。

### 8.2 建議模型設定

- Ridge 的 `alpha` 候選：`[0.1, 1, 10, 100]`。
- 邏輯斯迴歸採 L2，`C` 候選：`[0.01, 0.1, 1, 10]`；第一版不使用類別再平衡，避免破壞原始機率解讀。
- 樹模型第一輪固定 `learning_rate=0.05`、`max_iter=200`、`min_samples_leaf=100`；只比較 `max_leaf_nodes=[7, 15]`、`l2_regularization=[1, 10]`。
- 樹模型關閉可能隨機分割資料的內建 early stopping；若要提早停止，另用按時間分離的內層驗證區間。
- 固定亂數種子 `42`；保存套件版本、完整參數、特徵清單與資料指紋。
- 主要模型跨股票共同訓練；第一版不為每檔股票各自訓練，也不加入高維股票 ID 編碼。
- 為避免股票數較多的週支配目標，每個訓練週總權重相同，週內股票等權；評估同樣先按週算，再跨週平均。

上述候選是限制搜尋自由度的工程起點，不是對最佳績效的承諾。不同模型比較使用相近、預先登記的搜尋預算。

### 8.3 為什麼新增模型而非直接延伸固定效果迴歸

未來週的固定效果在預測時無法估計，不能從整段樣本估出的週效果取得未來共同衝擊。預測管線改用截止時已知的基準報酬、波動與其他狀態特徵。舊固定效果迴歸繼續用於研究描述，不充當線上預測模型。

## 9. 時間切分與避免污染

### 9.1 外層逐年外推

先以既有資料進行以下歷史開發評估：

| 外層測試年 | 可供訓練的歷史上限 |
|---|---|
| 2020 | 2019 年底以前，且標籤在訓練截止時已成熟 |
| 2021 | 2020 年底以前，且標籤在訓練截止時已成熟 |
| 2022 | 2021 年底以前，且標籤在訓練截止時已成熟 |
| 2023 | 2022 年底以前，且標籤在訓練截止時已成熟 |
| 2024 | 2023 年底以前，且標籤在訓練截止時已成熟 |

此表表示年度開始時的訓練範圍。外層測試年內每四個預測週依既定排程重訓一次，可加入截止時已成熟的新標籤；超參數與特徵版本在年度內凍結。這是逐期、可更新模型的評估，不可用該年後來的答案改寫較早預測。

時間序列應用過去資料預測之後的觀測，並在多個時間起點重複評估；多步預測也需依各自期間評分。[2]

### 9.2 內層選模型

在每個外層年度開始前，用其訓練資料內最後三個不重疊的 26 週區塊依序作驗證；每個驗證區塊之前至少有 104 個特徵週可訓練。每個內層折也要重建前處理與成熟標籤篩選。

- Ridge／樹回歸：以內層每週平均 Rank IC 為選模準則；同分時選較強正則化或較簡單模型。
- 分類：以內層每週平均 Brier score 選模。
- 資料不足以完成三折時，明確縮減折數並標記開發不足；正式模型至少要求兩個有效內層折。
- 記錄所有候選結果，不只保存勝出的參數。

### 9.3 切分單位與標籤成熟

所有股票必須以 `as_of` 週為切分單位，同週整批進同一側。不能直接對 ticker-week 長表使用隨機切分，也不能以列數機械切割造成同一週落在兩邊。

```python
train = rows[
    (rows.as_of < fit_cutoff)
    & (rows.label_end_at < fit_cutoff)
    & (rows.label_available_at < fit_cutoff)
]
```

1 週與 4 週各自篩選成熟標籤。不是固定 `gap=4` 就必然安全，應按實際期間、休市與資料發布延遲判定。純向前訓練不需要再機械刪掉全部測試後資料；若將來採用混合過去／未來的交叉驗證，需另設完整重疊排除規格，不可套用本版結果。

### 9.4 已看過的資料與真正新資料

2015–2024 已被研究、調整比對規則並檢視結果，即使新增時間切分，也只能稱歷史開發的樣本外預測，不能稱完全未接觸的最終測試。

新補的 2025–2026 資料也不會自動成為乾淨測試：要檢查是否參與名單選取、特徵設計、規則修訂或模型選擇。凍結規格後才取得的前瞻預測，是最清楚的新增證據。

若在最終測試或前瞻期看到結果後改方法，建立新版本，之後的資料才是該版本的新驗證。舊結果保留，不重新命名為未接觸測試。

## 10. 評估指標、校準與統計不確定性

### 10.1 主要指標：每週排名相關

```text
IC_w = SpearmanCorr(predicted_excess_return_w, realized_excess_return_w)
Delta_IC_w = IC_B,w − IC_A,w
主要比較 = mean(Delta_IC_w)
```

每週至少 30 檔可共同評分股票才計算該週 IC；其餘記為不足，另報涵蓋率。先逐週計算再平均，不能把全部股票週混成一個相關係數。報告同時列出 A、B 的 IC，避免「B 比很差的 A 好」被誤稱可用。

### 10.2 次要指標

| 任務 | 指標 | 解讀 |
|---|---|---|
| 相對報酬 | 每週平均 MAE／RMSE、相對 A 的誤差改善 | 預測數值是否更接近實現值 |
| 排名 | 前 20% 的平均超額報酬、跑贏基準比例 | 高分股票是否較強 |
| 機率 | Brier score、log loss、可靠度圖 | 機率是否具有實際意義 |
| 分類補充 | ROC-AUC、類別率、balanced accuracy | 不以 accuracy 單獨判定成功 |
| 覆蓋 | 預測率、可評分率、未成交率、資料中斷率 | 防止只挑容易的案例 |
| 穩定性 | 分年、產業、規模、稀疏度、當時市場狀態 | 是否只靠單一年或少數股票 |

基準比較需在相同預測樣本上進行。A 的全部可用樣本結果可另報，但不能用它直接比較 B 的較小樣本結果。

### 10.3 機率校準

校準圖檢查預測機率與實際事件頻率是否一致。[3] 若需要校準，建議用內層向前驗證產生的 out-of-fold 機率擬合 sigmoid 校準器，不使用模型對其自身訓練樣本的機率，也不使用外層測試標籤。

校準器與分類模型一起保存。少量資料時不要任意增加校準複雜度；未通過校準驗證的輸出標為未校準分數，不包裝成可靠的機率。

### 10.4 信賴區間與多重比較

- 對逐週的 A/B 成對差異做時間區塊 bootstrap，每次抽整個週區塊，保留同週橫斷面關係。
- 第一版設定主區塊長 8 週、重抽 2,000 次、固定種子；4 與 13 週作已登記敏感度分析。
- 4 週標籤重疊，不能把相鄰週當獨立樣本；其區塊長至少覆蓋預測期間，並檢查更長時間依賴。
- 報告 95% 區間、有效週數、年度分布及所有預先登記比較。
- 1 週 M2 對 M1 為唯一主要比較；其他結果標次要／探索性，不以多次嘗試中最好的一個宣告成功。

不能以舊迴歸 p 值作為新模型預測能力，也不能把訓練資料上的擬合度當樣本外成績。

## 11. 交易回測：將預測價值轉成可執行的檢驗

### 11.1 第一版策略

為與 1 週標籤一致，第一版採「本週首個交易日進場、最後一個交易日收盤退出」：

- 只做多、無槓桿，起始模擬資金建議新台幣 100 萬元。
- 依預測超額報酬選排名最高的 20 檔，等權目標，單檔上限 5%；不足 20 檔時剩餘資金留現金，不提高剩餘個股上限。
- 不使用未來報酬或未來是否有成交來決定入選名單。
- 第一版不以任意的機率門檻擇時，先隔離排序價值；若加入不交易門檻，須另在內層選定版本。
- 週末持有現金，現金利息第一版設為 0 並揭露。
- 即使相同股票連續兩週入選，也要計入兩週各自實際買賣的成本。

同時模擬三條策略：A 的排名策略、B 的排名策略、每週同進出時間持有 0050 的比較策略；另外列 0050 連續買入持有作背景。交易時間不同的策略需清楚標示。

### 11.2 事前可交易性

建議門檻為截止時已知的過去 20 個市場交易日日均成交金額至少新台幣 500 萬元。零成交日計入，資料缺失不能當成零；歷史不足或可靠度不足者不開新部位。

每笔訂單不超過過去 20 日均成交量的 1%。此門檻是初始容量假設，不能證明一定成交；尤其開盤交易還受開盤可成交量限制。

價格到漲跌停、停牌或缺乏可成交證據時，需依預先設定的保守規則判定未成交。只有日 OHLCV 時不足以重建開盤排隊、盤中成交與買賣價差，回測標記為日資料成交近似，不得宣稱逐筆可執行。

交易單位、零股時段、委託價格與歷史制度都需按有效日期設定。若第一版只模擬整張單位，股數向下取整，買不起的部位留現金，不假設任意小數股能在開盤成交。

### 11.3 成本與帳本

```text
buy_cost  = executed_buy_value × buy_fee_rate + minimum_fee_adjustment
sell_cost = executed_sell_value × (sell_fee_rate + applicable_tax_rate)
            + minimum_fee_adjustment
NAV = cash + marked_position_value + receivables
```

手續費、折扣、最低費用、證交稅、商品差異與歷史有效日期用成本表管理；正式交易評估前，需以適用券商與官方規則確認。本文不將專案中的既有固定稅費假設視為永久適用費率。

滑價以成交價相對參考價調整。若已調整買賣成交價，不得再重複扣相同滑價。另跑基準滑價的 2 倍壓力情境，完整列出假設。

每日保存現金、股數、價格、應收股利、公司行動、委託、成交、費稅與未成交原因。換手率由實際買賣金額除以資產計算，不以名單替換比例代替。

被迫跨週持有的停牌或無法賣出部位，持續占用資金，下一週不能假設已恢復現金。下市清算、最終估值或缺少回收資料均需保留狀態與敏感度情境，不能在資產曲線中消失。

### 11.4 4 週預測與部位重疊

第一版 4 週任務先評估預測，不直接將每週重疊的四週報酬串成一條績效。

若之後做交易，可選「每四週換倉一次」或「四個各占四分之一資金、每週依序建立的持倉批次」。方案要先固定，完整計入重疊部位、現金、成本與風險。不得讓每個批次都使用全額資金卻稱為無槓桿。

### 11.5 策略指標

由連續資金曲線計算總報酬、實際日數年化報酬、最大回撤、年化波動、換手、總費稅與資金利用率；若報 Sharpe，明確記錄無風險利率假設與報酬頻率。

不得用「每週平均報酬 × 52」代替複利績效。報酬排名有增益與交易可獲利是兩道不同驗收。

| `evaluation_weekly.parquet` | model_pair、as_of、horizon | A/B 指標、差值、共同可評分數、缺失數 |
| 交易帳本 | strategy_version、order_id／date | 委託、成交、股數、現金、成本、NAV、失敗原因 |
| `forecast_readiness.json` | run_id | 資料、模型、評估、交易各自是否就緒與阻斷原因 |

特徵表可以包含未來標籤尚未成熟的最新週。推論不得因 `y` 缺值而刪掉最新一批。標籤只能由訓練／評估端讀取，推論模組不依賴標籤檔。

每次預測的使用者介面至少顯示：資料截止、預測期間、比較基準、排名或機率、模型版本與資料是否完整。不將特徵重要性稱為原因或因果解釋。

## 16. 開發順序與每階段交付

### P0：時點資料與標籤正確性

工作：建立 availability 契約、修正 bfill、拆 X/y、修正最新文章歸週與上市前暖機；補基準資料，定義公司行動和 1w 標籤。

交付：資料字典、來源可用時間假設表、樣本排除報告、特徵白名單、標籤對照案例。

完成條件：未來資料追加不改變既有快照；缺值不冒充零；最新無標籤週可以建出特徵。

### P1：最小預測實驗

工作：完成 2020–2024 外層開發評估、Ridge A/B 與常數基準、逐週排名與成對比較。

交付：每筆樣本外預測、逐週指標、分年度比較、試驗登記與失敗紀錄。

完成條件：每筆預測可追溯至訓練截止與模型；能明確回答 PTT 是否優於價格基準。結果不佳仍是完成實驗，不應為追求正結果持續換規格。

### P2：機率、四週與交易驗證

工作：新增分類與校準、四週連續標籤、受限樹模型、1w 成交帳本與成本壓力測試。

交付：校準報告、各期間績效、連續 NAV、訂單與公司行動帳本、成交資料限制。

完成條件：四週重疊不被當獨立觀測；交易帳本收支對平；相同名單重複買賣仍正確扣成本。

### P3：最新資料與前瞻紀錄

工作：補齊近期來源，建立持續增量抓取、固定排程與預測快照，開始只做模擬的前瞻運作。

交付：每週觀察名單、資料狀態、不可改寫的預測歷史、標籤成熟後評分。

完成條件：連續 12 個預測週按規格完成或正確跳過，所有跳過可追溯。12 週只驗證運作可靠度，不能據此宣稱長期獲利。

### P4：擴充來源與宇宙

工作：依 P1/P2 找到的實際缺口，加入新聞、月營收、歷史時點宇宙或其他市場；逐項做增量比較。

交付：與既有 A/B 使用同樣本的擴充實驗，新增來源成本與收益評估。

不要把「加入資料後曾跑出較高成績」當作必然改善；需保留未接觸資料確認。

## 17. 驗收測試與決策門檻

### 17.1 必須通過的正確性測試

| 測試 | 必須成立的結果 |
|---|---|
| 未來資料不變性 | 新增 cutoff 後資料或價格修訂，不改變已保存 cutoff 特徵 |
| 可用時間測試 | 事件早發生但晚公開／晚取得的資料，不進入早期特徵 |
| 持股回填測試 | 第一筆公開持股值之前保持缺值 |
| 暖機測試 | 上市前空白不變成 8／52 週的零討論歷史 |
| 來源中斷測試 | PTT 抓取失敗時不是文章數零 |
| 最新推論測試 | y 尚不存在時仍可產生本期 X 與預測 |
| 欄位隔離測試 | 注入未來報酬欄不會被白名單選入 |
| 時間切分測試 | 同週不跨 train/test；所有訓練標籤已成熟 |
| 四週標籤測試 | 週末跳空計入連續持有報酬，ret_fwd4 不充當累積報酬 |
| 休市測試 | 全週休市記 skip；短週按實際期間計算 |
| 公司行動測試 | 拆併股、股利、減資退還不造成虛假價格獲利或雙算 |
| 名單選擇測試 | 隱藏或改變未來報酬缺值狀態不改變已產生訂單 |
| 成本帳本測試 | 現金＋持倉＋應收對平；滑價與股利不重複扣／加 |
| 未成交測試 | 買不到留現金，賣不掉保留持倉及占用資金 |
| 模型重播測試 | 相同模型、設定與快照產生一致結果 |

這些測試針對會實質扭曲預測與交易結果的錯誤，並非只檢查函式能否執行。

### 17.2 證據分層與上線條件

| 層級 | 建議門檻 | 通過後能說什麼 |
|---|---|---|
| 工程正確 | 上述必要測試通過；資料血緣與缺口完整 | 系統可按規格產生預測 |
| 歷史開發增益 | B 自身平均 IC > 0；B−A 的平均 IC > 0 且主區塊 95% 區間下限 > 0；五個開發測試年至少三年增益為正 | 在指定歷史開發設定下，PTT 有增量訊號 |
| 機率可解讀 | Brier 優於同樣本 A，可靠度圖與區間已檢查 | 可提供經驗支持的機率輸出 |
| 交易候選 | B 成本後收益為正、優於 A；成本壓力後結論不崩解；回撤不超過預先填定的風險上限 | 值得繼續前瞻模擬 |
| 前瞻證據 | 先累積 12 週驗證運作，至少 52 週再作第一輪年度評估；仍報區間與市場環境 | 具真實時間的預測紀錄，不保證未來獲利 |

交易風險上限須在開始交易評估前寫入實驗表，依實際使用目的決定；缺少此值時不宣告通過交易層驗收。52 週亦不是統計充分性的保證，需依效果大小、時間相依與環境覆蓋判斷。

以上增益門檻是本版預先登記的決策規則，不等於已校正所有模型搜尋與歷史選樣問題。事後宇宙與回溯資料限制仍需隨結果揭露。

如果 B 沒有穩定優於 A，維持 A 作為預測基準，PTT 可以保留為研究、監測或熱度預測來源；報酬任務結論明確寫為「尚無足夠增量預測證據」。

## 18. 運作監控與版本更新

- 每次記錄資料截止、來源完整性、最新資料時間、特徵缺失率與預測數。
- 若原始價格／基準不完整，停止受影響輸出；若 PTT 不完整，僅在 A 已驗證且價格完整時明確降回 A。
- 檢查特徵分布、預測分布、稀疏度組成與缺失率是否偏離訓練期；異常觸發調查，不自動重寫歷史或選新模型。
- 依預定四週節奏重訓；超參數年度更新。資料修正與緊急更新另記版本及原因。
- 最近 13／26／52 週在標籤成熟後分別評估，短窗只作監測，不因短期績效反覆換模型。
- 對缺資料、逾時、模型載入失敗與重大效能退化保存明確狀態；不顯示過期分數為最新預測。
- 原研究 `formal_main_return` 旗標保留；預測另用 `forecast_readiness`。前者不因預測測試通過而解除，後者也不因論文控制變數補齊就自動通過。
